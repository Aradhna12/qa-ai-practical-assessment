BASIC LEVEL QA / SDET kubectl

Kubernetes QA POC — Visual Guide

Basic cluster validation for Quality Engineers: deploy an app, verify pods/services, check logs, scale, observe a negative failure, and clean up.

Appnginx-demo
Namespaceqa-demo
Replicas2
Imagenginx:1.27-alpine

01 — Cluster connectivity

First QA gate: confirm the cluster is reachable and at least one node is Ready.

PowerShell — kubectl get nodes -o wide
PS D:\qa-ai-practical-assessment> kubectl get nodes -o wide NAME STATUS ROLES AGE VERSION INTERNAL-IP OS-IMAGE docker-desktop Ready control-plane 12m v1.31.1 192.168.65.3 Docker Desktop ✔ Node Ready — cluster is usable for QA deploy checks

02 — Create QA namespace & apply manifests

Isolate POC resources in qa-demo, then apply Deployment + Service.

PowerShell — kubectl apply
PS> kubectl apply -f kubernetes/manifests/namespace.yaml namespace/qa-demo created PS> kubectl apply -f kubernetes/manifests/deployment.yaml deployment.apps/nginx-demo created PS> kubectl apply -f kubernetes/manifests/service.yaml service/nginx-demo created

03 — Verify pods are Running / Ready

Core functional check: desired replicas available, containers ready, no CrashLoop.

kubectl get pods -n qa-demo -o wide
NAME READY STATUS RESTARTS AGE IP nginx-demo-6f8c9d7b4d-2xk9p 1/1 Running 0 45s 10.1.0.14 nginx-demo-6f8c9d7b4d-9m2qw 1/1 Running 0 45s 10.1.0.15
  • PASS READY = 1/1 for both pods
  • PASS STATUS = Running
  • PASS RESTARTS = 0
  • PASS replica count = 2

04 — Deployment & Service health

Confirm rollout finished and Service has endpoints.

kubectl get deploy,svc,endpoints -n qa-demo
NAME READY UP-TO-DATE AVAILABLE AGE deployment.apps/nginx-demo 2/2 2 2 1m NAME TYPE CLUSTER-IP EXTERNAL-IP PORT(S) AGE service/nginx-demo ClusterIP 10.96.120.44 <none> 80/TCP 1m NAME ENDPOINTS AGE endpoints/nginx-demo 10.1.0.14:80,10.1.0.15:80 1m ✔ Available=2 and endpoints populated — traffic path is healthy

05 — Describe resource & inspect logs

QA debug skills: events from describe + application log smoke check.

kubectl describe deploy nginx-demo -n qa-demo
Replicas: 2 desired | 2 updated | 2 total | 2 available Conditions: Type Status Available True Progressing True Events: Normal ScalingReplicaSet Deployment scaled up to 2
kubectl logs -n qa-demo -l app=nginx-demo --tail=5
/docker-entrypoint.sh: Configuration complete start worker processes 10.1.0.1 - - [11/Sep/2026] "GET / HTTP/1.1" 200

06 — Scale & rollout verification

Basic resilience check: scale replicas and wait for rollout success.

kubectl scale & rollout status
PS> kubectl scale deploy/nginx-demo -n qa-demo --replicas=3 deployment.apps/nginx-demo scaled PS> kubectl rollout status deploy/nginx-demo -n qa-demo Waiting for deployment "nginx-demo" rollout to finish: 2 of 3 updated replicas are available... deployment "nginx-demo" successfully rolled out

07 — Negative test (bad image)

QA must also prove failure visibility: ImagePullBackOff / ErrImagePull.

kubectl get pods -n qa-demo -l app=bad-image-demo
NAME READY STATUS RESTARTS AGE bad-image-demo-7c9f5d8b9-abc12 0/1 ErrImagePull 0 20s or ImagePullBackOff
  • DETECT Pod not Ready
  • DETECT Image pull error in events
  • PASS Failure is observable via kubectl
  • Delete negative deploy after demo

08 — Automated QA script result

Repeatable pass/fail gate for BASIC Kubernetes health checks.

09 — Cleanup

Good QA hygiene: remove POC resources when demo is finished.

kubectl delete
